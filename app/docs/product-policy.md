# 스톨로지 로컬앱 제품 정책

범위: 개인 Mac용 로컬앱. 사용자 작업계획(2026-11-13)과 PDF 필기·명시적 분석 결정(2026-11-15)이 정책의 원본이며, 이 문서는 그 내용을 로컬앱 전용 ID로 정리한다. 기존 웹 제품의 DEC·QA와 Excel 실행 기록을 대체하지 않는다. **정책 확정은 구현·실기 통과를 뜻하지 않는다.** 실행 결과는 로컬앱 QA에 별도로 기록한다.

## 제품 방향 · 타깃과 후속 검토

목표 사용자는 AI에 익숙하지 않은 대학생이다. 수업 필기와 자료 정리를 앱 안에서 수행하고, 쌓인 로컬 문서를 이후 Claude·Codex 등에서 쉽게 활용할 수 있는 학습 공간을 지향한다. 초기 구현 대상은 기존과 같이 개인 Apple Silicon Mac이다.

연결한 구독 계정의 공식 CLI를 앱 내부의 학습 인터페이스에서 사용하는 확장도 검토한다. 경쟁 조사와 방향 제안에 내부 자료 질문, 외부 AI의 파일 활용, 우선순위와 검증 계획을 정리했다. 텍스트 대화는 ADR-017의 범위로 도입한다. 자료 연결·학습 레시피 등 나머지 확장은 제안이다. 사용자에게 보이는 과목 폴더를 구현할 때는 LOCAL-P06·P07·P11 및 관련 ADR의 인증·실행·저장 경계를 먼저 구체화한다.

## LOCAL-P01 · 과목과 화면

좌우 사이드바는 원래의 시스템 유리 효과와 배경 그라데이션이 비치는 색감을 유지한다. 포커스 이탈 시 색상을 유지하기 위해 유리 효과를 단색 배경으로 대체하지 않는다. 지원되는 macOS에서는 다른 앱으로 포커스를 옮겨도 유리 외형과 색감을 유지한다. 실제 키보드 포커스와 입력 대상은 정상적으로 전환한다. 호환성 경계는 ADR-020을 따른다.

과목 이름으로 워크스페이스를 생성·선택한다. 과목마다 자료·초안·지식지도를 분리한다. 왼쪽은 과목, 중앙은 문서, 오른쪽 위는 자료 폴더 트리, 구분선 아래는 작성 중 초안이다. 처음 선택한 과목은 중앙에 빈 Markdown 초안을 연다. 같은 창에서 다른 과목을 보다가 돌아오면 해당 과목에서 마지막으로 보던 문서나 지식지도를 복원한다. 초안을 클릭하면 중앙에서 재개한다. 지도에서 돌아오면 이전 문서·선택·편집 위치를 복구한다.

제목 막대의 새 노트와 오른쪽 사이드바 버튼 사이에 단축키 보기 버튼을 둔다. 단축키 패널은 버튼 아래 오른쪽 사이드패널 자리에 기본 너비 340pt로 표시한다. AI 설정과 같은 라벤더 배경과 기존 구분선을 사용한다. 패널이 열린 동안 중앙 노트를 편집할 수 있고, 키보드 아이콘을 다시 누르거나 패널 오른쪽 위 닫기 버튼을 누르면 닫힌다. 패널 제목 아래에는 목록을 스크롤해도 자리를 유지하는 2pt 섹션 구분선을 둔다.

워크스페이스 행을 우클릭하면 해당 행에 테두리를 표시하고 이름 변경과 빨간 휴지통 아이콘의 삭제 메뉴를 연다. 이름 변경은 해당 행에서 바로 편집하며 Enter 또는 포커스 이탈로 저장하고 Esc로 취소한다. 삭제 대상 이름과 관련 데이터 전체가 사라진다는 경고를 확인한 뒤, 두 번째 창에서 영구 삭제를 선택해야 삭제한다. 어느 단계에서든 취소할 수 있다.

좌우 사이드바의 상시 접기·펼치기 아이콘은 표시하지 않는다. 접힌 상태에서는 창 가장자리, 펼쳐진 상태에서는 해당 사이드패널 내부 바깥쪽 가장자리의 세로 전체 40pt 영역에 마우스를 올리면, 안쪽으로 옅어지는 가로 56pt 라벤더 그라데이션과 중앙의 동작 방향 화살표·그 아래 `접기` 또는 `펼치기` 문구를 표시한다. 접기 그라데이션은 유리 사이드패널의 높이와 22pt 둥근 모서리 안에서만 표시한다. 펼쳐져 있으면 창 바깥 방향 화살표와 `접기`, 접혀 있으면 안쪽 방향 화살표와 `펼치기`를 표시한다. 마우스가 벗어나면 안내를 숨기며, 해당 클릭 영역 어느 높이에서 클릭해도 접거나 펼친다. 호버만으로 패널 상태를 바꾸지 않는다. 그라데이션의 안쪽 여분은 클릭을 가로채지 않는다. 각 사이드바는 독립적으로 접고 펼치며 접힌 공간은 중앙 문서가 차지한다. 과목·문서 선택·검색어·폴더 펼침 상태를 유지하고, 접기만으로 문서를 다시 열거나 본문을 변경하지 않는다. 전환은 240ms 슬라이드이며 이동 중 다시 누르면 현재 위치에서 새 방향으로 이어진다. macOS ‘동작 줄이기’ 설정에서는 즉시 전환한다. 사이드바 파일 제목 편집 중에는 편집을 마친 뒤 접을 수 있다. 접힘 상태는 현재 창 세션에서 유지하며 앱 재실행 시 양쪽을 펼친다.

중앙 문서와 오른쪽 사이드바 사이의 12pt 경계에 마우스를 올리면 좌우 크기 조절 커서와 강조선을 표시하고 드래그로 너비를 조절한다. 기본 너비는 340pt, 최소 너비는 220pt이며 최대 너비는 중앙 문서와 오른쪽 사이드바가 1:1이 되는 지점이다. 창 바깥 여백·왼쪽 사이드바·조절 경계를 제외한 공간을 기준으로 계산하며 고정된 최대 pt 제한을 두지 않는다. 창이 좁아지면 표시 너비를 제한하고 다시 넓히면 선택한 너비로 복구한다. 자료·학습도우미가 같은 너비를 사용하며 접기·펼치기 후에도 유지한다. 선택한 너비는 현재 창 세션에서만 유지하고 앱 재실행 시 기본값으로 시작한다. 접힌 상태나 접기 애니메이션 중에는 조절 경계를 숨긴다. 최소 너비보다 더 축소하는 방향으로 드래그하면 패널 자체는 220pt로 유지하고, A안 라벤더 반투명 그라데이션과 중앙 오른쪽 화살표로 덮는다. 덮개는 오른쪽이 진하고 왼쪽으로 옅어지며 텍스트나 버튼 배경을 추가하지 않는다. 패널·덮개는 추가 드래그 거리만큼 함께 오른쪽으로 이동한다. 화살표는 드래그 구분선 오른쪽에 남은 영역의 중앙을 따라 이동한다. 남은 영역이 화살표보다 좁아지면 화살표 크기를 유지하고 왼쪽에 맞춰 오른쪽부터 잘라내며, 영역이 없어지면 완전히 사라진다. 드래그 중 중앙 문서는 최소 너비 때의 공간을 유지하며, 손을 놓으면 현재 위치에서 접기 전환을 이어 가고 중앙 문서를 확장한다. 놓기 전에 220pt 이상으로 되돌리면 내용이 복구되고, Esc 또는 창 포커스 이탈 시 시작 너비로 취소한다. 드래그로 접은 뒤 다시 펼치면 220pt로 열린다. 파일 이름 수정 또는 입력기 조합 중에는 드래그를 시작하지 않는다.

왼쪽 사이드바도 중앙 문서와의 12pt 경계를 드래그해 너비를 조절한다. 기본·최소 너비는 기존 크기인 196pt이며, 오른쪽 패널과 여백을 제외하고 중앙 문서 너비를 확보하는 범위까지 확장한다. 최소 너비보다 왼쪽으로 더 끌면 패널 폭은 유지하고 패널·라벤더 덮개를 함께 왼쪽으로 이동한다. 덮개는 왼쪽이 진하고 오른쪽으로 옅어진다. 왼쪽 화살표는 구분선 왼쪽에 남은 영역의 중앙을 따라 이동하며, 24pt보다 좁아지면 오른쪽 정렬로 전환하고 왼쪽부터 잘려 사라진다. 놓으면 현재 위치에서 접히고, 반대로 되돌리면 복구되며 Esc·창 포커스 이탈은 시작 너비로 취소한다. 드래그로 접은 뒤 다시 펼치면 196pt로 열린다. 선택 과목·문서·채팅 초안은 유지하며, 너비는 현재 창 세션에서만 기억한다.

자료/학습도우미 탭은 오른쪽 패널 안에서 전환한다. 두 탭은 가는 밝은 테두리가 있는 반투명 흰색 알약 트랙으로 묶는다. 선택한 항목은 옅은 그림자가 있는 흰 유리 알약, 진한 글자, 인디고 아이콘으로 강조한다. 탭은 별도 접기 아이콘 없이 헤더의 가용 너비를 사용한다. 탭의 실제 텍스트·아이콘 너비와 여백을 확보할 수 없으면 두 탭 모두 아이콘만 표시하며, 다시 넓히면 텍스트를 복구한다. 아이콘 전용 상태에서도 선택 강조와 접근성 이름을 유지한다. 입력창은 모서리 24pt의 반투명 흰 유리 캡슐이며 밝은 가는 테두리와 아래로 옅은 그림자를 둔다. 입력창 하단은 통합 모델 목록·effort·전송 아이콘 한 줄로 구성한다. 모델과 effort는 입력창 좌측 하단에 배경·테두리 없는 버튼으로 표시한다. 클릭 영역은 높이 28pt를 유지하고 마우스를 올린 버튼에만 높이 22pt·모서리 6pt의 옅은 강조 면을 표시한다. 하단 전송 안내는 `⌘ + Enter 전송` 표기로 오른쪽 정렬한다. 모델 버튼 앞의 작은 원은 선택한 모델의 상태를 메뉴를 열지 않아도 보여 준다. 칩이 좁아지면 모델 이름을 말줄임표로 줄이고 전체 이름은 접근성 정보에 남긴다. 전송 버튼은 모델·effort 선택부의 호버 면과 동일한 22pt 높이의 인디고 원형이며 같은 행 중심에 정렬한다. 전송·중지 아이콘은 선택부 화살표와 같은 8pt 크기를 사용한다. 보낼 수 없을 때는 회색으로 꺼진다. 별도 Codex/Claude 공급자 버튼과 연결 버튼은 두지 않는다. 통합 목록에서 Claude·Codex·Antigravity 모델을 함께 표시하고 항목 이름에 공급자를 붙인다. 각 항목 오른쪽의 작은 원은 CLI 설치·로그인과 현재 모델 목록 조회가 확인되면 초록색, 미연결·미확인·조회 실패·목록에 없는 저장 선택이면 회색이다. 초록색은 연결·목록 기준이며 추론 성공이나 남은 한도를 보장하지 않는다. 연결 관리는 왼쪽 구독 계정 연결에서 한다. 전송은 위쪽 화살표 아이콘이고 응답 중 같은 버튼을 정지 사각형 아이콘으로 바꿔 중지할 수 있다. 별도 중단 버튼은 두지 않는다. 전송·중지 버튼은 호버 툴팁을 표시하지 않고 접근성 이름은 유지한다. 첫 답변을 기다리는 동안 말풍선에 점 세 개가 순서대로 위아래로 움직이며 상단의 중복 대기 문구는 표시하지 않는다. 동작 줄이기 설정에서는 점을 정지 상태로 표시한다. Codex·Claude의 모델 목록과 지원 effort는 각각 공식 CLI에서 조회한다. Claude·Codex 모두 버전이 명시된 모델만 표시하며 `기본 모델`과 `자동 버전` 별칭은 표시하지 않는다. 기존 기본·별칭 선택은 CLI가 알려주는 정확한 버전으로 전환해 저장하며, 확인할 수 없으면 사용자가 버전 모델을 선택하기 전까지 전송하지 않는다. 모델 선택 시 해당 공급자로 전환하며 대화·초안은 기존 공급자별로 유지한다. effort는 모델별로 기억한다. 선택한 모델이 지원하는 단계만 제공하고 미지원 모델에서는 비활성화한다. 전송 시 버전과 effort를 고정하며 지원하지 않는 조합은 실행 전에 알린다. 공급자별 모델 선택은 재실행 후에도 유지하며 같은 공급자 내 모델 변경은 대화·초안을 초기화하지 않는다. 요청 중 모델 선택은 잠그고 전송 시점 모델·effort를 해당 턴에 기록한다. 모델 목록 재조회 실패는 오류를 표시하고 저장된 선택을 유지하며 메뉴에서 다시 불러올 수 있다. 학습도우미는 반투명 메시지 말풍선, 선택 가능한 텍스트, 답변별 복사·명시적 재시도, 하단 입력창을 제공한다. 내 질문은 오른쪽, 답변은 왼쪽에 놓고 이름표 없이 정렬과 색으로 구분한다. 말풍선은 글 길이에 맞추되 패널 폭의 86%를 넘지 않으며 말한 쪽 아래 모서리만 작게 깎는다. 답변 작성 중·중단됨·실패 상태는 답변 말풍선 아래 복사·재시도 옆에 표시한다. Enter는 줄바꿈, ⌘Enter는 전송이며 한글 조합 중 전송하지 않는다. 모드·과목·공급자 전환 시 초안을 보존하고 기록을 섞지 않는다. 이미지는 입력란 붙여넣기(⌘V)·끌어놓기·조작 줄 맨 왼쪽 + 버튼으로 첨부한다. 글자와 이미지가 함께 복사된 경우 붙여넣기는 글자를 우선한다. 첨부 이미지는 입력란 안이 아니라 입력창 바로 위 가로 줄에 `Image #N` 이름표가 붙은 썸네일로 표시한다. 썸네일 줄은 대화 영역을 밀어 올리지 않고 그 위에 겹치며, 겹치는 아래쪽 대화만 그라데이션으로 투명하게 사라진다. 스크롤 막대는 표시하지 않고, 넘친 쪽 좌·우 가장자리를 흐리게 처리해 더 있음을 알린다. 가로 스크롤이나 썸네일을 잡아 끌어서 넘긴다. 썸네일에 마우스를 올리면 오른쪽 위에 X 버튼이 나타나 첨부를 취소할 수 있다. 한 번에 10장까지 첨부할 수 있다. PNG·JPEG·GIF·WebP는 원본을 그대로 보내고, 그 밖의 형식이나 긴 변 2048px 또는 약 3.6MB를 넘는 이미지는 줄여서 다시 인코딩한다. 이미지만 첨부해도 전송할 수 있다. 첨부 이미지는 전송 요청에만 담고 앱 저장소에는 남기지 않는다. 대화 기록에는 장수만 저장해 내 질문 말풍선에 `[Image #N]`으로 표시한다. 다시 시도는 텍스트만 다시 보낸다.

학습도우미 답변은 제목·강조·목록·인용·표·코드 블록의 Markdown 서식을 읽기 좋게 표시한다. Mermaid 코드 블록은 답변 완료 후 차트로 표시하고 원문을 펼쳐 볼 수 있다. 작성 중·문법 오류에서는 원문을 보존한다. 저장과 복사는 원래 Markdown을 유지한다. 외부 이미지 자동 로드와 원문 HTML 실행은 하지 않는다. 링크는 주소와 텍스트를 표시한다. ADR-021을 따른다.

## LOCAL-P02 · 작성·저장·복구

문서 상단의 저장·삭제와 ⌘S를 제공한다. 내용 없는 미저장 초안의 저장·삭제는 비활성화한다. 사용자가 폴더에서 명시적으로 생성한 노트는 비어 있어도 저장·삭제할 수 있다. 공백뿐인 초안을 파일이나 초안 목록에 누적하지 않는다. 입력 유휴 후 초안을 자동 보관하고 과목·문서·지도 전환 및 종료 때 즉시 보관한다. 저장하지 않은 초안도 재실행 후 복구할 수 있어야 한다.

일반 `새 노트`로 시작한 초안의 첫 저장은 제목과 현재 과목의 폴더 트리를 함께 보여 주는 창에서 한다. 과목 루트가 기본값이고 새 폴더를 만들 수 있다. 취소하면 초안으로 남는다. 이름이 충돌하면 덮어쓰지 않고 구분되는 이름을 제안한다. 저장 후 작성 중에서 자료 트리로 이동한다. 이후 편집은 자동 저장하며 저장 버튼과 ⌘S는 즉시 저장한다. 실패한 저장을 완료로 표시하지 않고 기존 내용과 복구 가능한 입력을 보존한다. 늦게 끝난 저장은 더 최신 저장을 덮어쓰지 않는다.

## LOCAL-P03 · Markdown 편집

노트 본문은 SUIT 16pt, 최소 줄높이 26pt를 사용한다(B안). 일반 문단 뒤에는 10pt를 더하고, 연속한 번호·불릿·체크리스트 항목 사이에는 4pt를 더한다. 한 항목이 화면 폭에 따라 여러 줄로 접히면 내부 줄높이는 26pt를 유지한다. 제목은 기존 글자 크기를 유지하며 위 24pt·아래 8pt를 추가하되 문서의 첫 제목 위에는 추가하지 않는다. 문단 뒤와 다음 제목 위 여백은 합산한다. 사용자가 입력한 빈 줄은 26pt이며 문단 여백을 더하지 않는다. 표·이미지·코드 블록의 전용 배치는 유지하고, 블록 주변 빈 곳의 커서 위치 계산도 26pt 기준으로 맞춘다.

UTF-8 Markdown이 정본이다. 제목·문단·굵게·기울임·목록·체크리스트·인용·링크·이미지·코드블록·표를 입력 즉시 서식에 반영한다. 한글 조합 중 문서 전체 교체나 커서 재설정을 하지 않는다. 받침 수정·한영 전환·선택·붙여넣기·실행 취소·저장 후 재열기의 정확성을 유지한다. 문서 본문은 불투명하게 유지하고 제어부에 인디고·글래스·시스템 글꼴·기존 곡률과 여백을 적용한다.

노트 본문을 우클릭하면 아이콘이 있는 `코드 블록`·`표`·`다이어그램` 메뉴가 열린다. 텍스트 삽입 커서가 있는 줄이 비었거나 공백만 있으면 그 줄에, 내용이 있으면 바로 다음 줄에 삽입한다. 코드 블록은 안에서 바로 입력할 수 있고 표는 빈 2×2로 시작한다. 다이어그램은 캔버스에서 `완료`를 누르면 같은 규칙으로 삽입한다.

표·다이어그램·코드 블록 아래의 노트 빈 영역을 클릭하면 해당 줄에서 본문을 입력한다. 좁은 표의 오른쪽 빈 영역을 클릭하면 같은 높이에서 본문을 쓰며, 이 글은 표 셀과 별도로 저장한다. 블록 바로 뒤에서 Backspace를 한 번 누르면 블록 전체를 지우고 ⌘Z로 복원한다. 코드 안에서는 일반 문자 편집을 유지한다.

편집 가능한 본문에서 ⌘⇧A로 머리행을 포함한 빈 2×2 표를 넣는다. 표 오른쪽·아래 가장자리에 포인터를 올리면 조절 손잡이(+)가 나타난다. 손잡이는 페리윙클에서 라벤더로 흐르는 워시이며, 표와 맞닿는 가는 선에서 시작해 표에서 멀어질수록 옅어진다. 손잡이를 클릭하면 열이나 행 하나를 추가한다. 열은 기본 140pt 너비로, 행을 추가할 때 표가 아래로 길어지듯 열을 추가하면 표가 오른쪽으로 넓어진다. 표가 본문 폭에 닿으면 그 폭 안에서 열을 고르게 나눈다. 바깥쪽으로 끌면 추가하고 안쪽으로 끌면 끝에서 삭제한다. 드래그하는 동안 예상 행·열 개수대로 표와 뒤따르는 본문 배치가 즉시 바뀐다. 열 손잡이는 좌우, 행 손잡이는 위아래 양방향 커서를 사용한다. 손을 놓으면 변경을 확정하며 한 번의 실행 취소로 되돌린다. 표 내부 구분선을 끌면 인접 열의 너비 또는 위쪽 행의 높이가 바뀐다. 셀을 한 번 클릭하면 선택하고 방향키로 이동한다. 드래그하면 직사각형 범위를 선택한다. 선택한 셀을 우클릭하면 왼쪽·가운데·오른쪽 정렬 세 항목만 표시하며 선택 범위에 일괄 적용한다. 텍스트를 편집 중인 셀을 우클릭하면 메뉴를 열지 않는다. 텍스트는 세로 중앙에 배치한다. 셀을 두 번 클릭하면 편집하며 Enter로 셀 안에서 줄을 바꾼다. 셀을 편집할 때 선택한 텍스트에 본문과 같은 굵게·기울임·밑줄·취소선·인라인 코드 단축키를 적용한다. 편집 중에도 인라인 서식을 바로 표시하고 서식 기호는 숨긴다. 선택 없이 서식 단축키를 누르면 이어서 입력할 글자에 적용한다.

렌더링된 표 다음의 첫 Markdown 구분 줄은 화면에서 접는다. 표를 넣으면 표 행 조절 손잡이 바로 아래에서 본문 입력을 이어가며, 첫 글자를 입력해도 줄 위치가 바뀌지 않는다. 추가로 입력한 빈 줄은 표시한다.

독립된 화살표 입력(`->`, `<-`, `<->`, `=>`, `<=`, `<=>`와 긴 형태)은 Space로 확정하면 유니코드 화살표로 변환한다. 코드·링크·HTML·붙여넣기·입력기 조합을 보호하고 변환은 실행 취소할 수 있다. 본문의 ⌘D는 단어에서 괄호·문장·문단·블록·전체 문서로 선택 영역을 확장하며 내용을 변경하지 않는다. 세부 입력 범위와 예외는 [단축키 안내](keyboard-shortcuts.md)를 따른다.

노트 문서 상단의 삭제·저장 왼쪽에 다이어그램 버튼을 둔다. 버튼을 누르거나 ⌘⇧D를 입력하면 중앙 문서 영역 전체가 캔버스로 바뀌고 상단 버튼은 `취소`·`완료`가 된다. 캔버스는 ⌘+·⌘−로 확대·축소한다. 캔버스의 가로·세로 스크롤바는 숨긴다. 선택 도구(V)로 빈 곳을 잡아 끌면 화면의 그림이 포인터를 따라 이동한다. 미니맵의 오른쪽 끝은 제목 구분선의 오른쪽 끝에 맞춘다. 미니맵의 오른쪽과 아래 여백은 각각 14pt이며, 왼쪽 하단 상태 문구의 글줄 하단을 미니맵 하단에 맞춘다. 미니맵에는 전체 캔버스의 축소 그림과 현재 화면 테두리만 표시한다. 캔버스를 이동하거나 확대·축소하면 보라색 테두리가 갱신된다. 미니맵에서 테두리 밖을 클릭해 해당 위치로 이동하거나 테두리 안을 잡고 끌어 탐색할 수 있다. 노트에서는 편집 배율과 관계없이 도형·펜 선·화살촉·글자의 외곽을 감싸는 사각형으로 잘라 표시한다. 제목 아래에는 부제목 한 줄 높이만큼 구분선과 도구 줄을 올리고, 둘의 왼쪽 끝을 제목에 맞춘다. 구분선 아래에서 첫 도구 버튼까지 8pt를 띄운다. 캔버스 위 도구 줄은 PDF 필기 도구 줄과 같은 모양이며 선택·영역 선택·사각형·타원·마름모·화살표·펜·글자와 실행 취소·다시 실행·삭제를 제공한다. 영역 선택(M)으로 사각 범위를 끌면 그 안에 완전히 들어온 요소를 선택한다. 선택한 요소를 함께 이동하거나 삭제하고, 선 색·채우기·텍스트 색을 해당 속성을 지원하는 요소에 일괄 적용할 수 있다. 각 변경은 한 번의 실행 취소로 되돌린다. 도형은 드래그로만 만들고, 도형을 더블클릭하거나 선택한 채 Enter를 누르면 도형 안에 글자를 쓴다. 화살표 끝을 도형 안이나 테두리 바깥 8pt 안에 놓으면 도형에 붙어 도형을 옮길 때 함께 움직인다. 붙을 도형은 끝을 끄는 동안, 그리고 화살표 도구로 포인터를 올렸을 때 보라색 테두리와 네 변 가운데의 점으로 표시한다. 변 가운데 점에서 8pt 안에 놓으면 끝을 그 변의 가운데에 고정하고 그 점을 채워 표시하며, 그 밖에 놓으면 끝이 상대편을 향하는 테두리 지점을 따라간다. 한 도형 안에서 시작하고 끝나는 화살표는 만들지 않는다. 도형에 붙은 끝은 화살표 몸통을 끌어도 움직이지 않으며, 끝의 손잡이를 끌어 다른 곳에 붙이거나 뗀다. Shift를 누른 채 끌면 붙지 않은 끝을 45° 간격의 방향에 맞춘다. 화살표의 글자는 선의 가운데에 놓고 글자 자리만큼 선을 끊는다. 도구 줄의 화살표 버튼을 누르면 버튼 아래에 단방향 화살표·양방향 화살표·화살촉 없는 선을 고르는 메뉴가 열리고, 고르면 바로 그 종류로 그린다. 메뉴에는 현재 종류에 체크 표시를 하고, 화살표 버튼의 그림은 고른 종류를 따른다. 단축키 A는 메뉴를 열지 않고 마지막에 고른 종류로 그리며, 고른 적이 없으면 단방향 화살표로 그린다. 마지막에 고른 종류는 앱 실행 중 유지한다. 새로 그리는 화살표는 실선 직선이다. 화살표를 우클릭하면 그 화살표를 선택하고 컨텍스트 메뉴를 연다. 메뉴는 `점선으로 전환`(점선이면 `실선으로 전환`), `꺾인 선으로 변환`(꺾여 있으면 `직선으로 변환`), 그리고 단방향 화살표·양방향 화살표·화살촉 없는 선을 제공한다. 여러 요소를 선택한 채 그 안의 화살표를 우클릭하면 선택한 화살표 모두에 적용하고, 각 변경은 한 번의 실행 취소로 되돌린다. 도형·펜·글자와 빈 곳에는 컨텍스트 메뉴를 두지 않는다. 캔버스 오른쪽에는 화살표 설정 버튼을 두지 않는다. 꺾인 선은 직각으로만 꺾이며 붙은 도형의 변 가운데에서 수직으로 드나든다. 꺾이는 경로는 자동으로 정하고, 꺾이는 지점을 직접 옮기는 기능은 두지 않는다. 그리기 도구 버튼을 더블클릭하면 그린 뒤에도 그 도구를 유지하고 버튼에 점을 표시한다. 화살표 도구는 누르면 메뉴가 열리므로 메뉴의 `계속 그리기`로 유지한다. 다른 도구를 고르거나 Esc를 누르면 해제한다. 캔버스 오른쪽에서 선 색·채우기·텍스트 색 버튼을 누르면 32색 팔레트가 열린다. 도형에는 세 색을 각각 지정하고, 독립 글자는 텍스트 색, 펜은 선 색, 화살표는 선 색과 글자 색을 지정한다. 채우기는 없음으로 지울 수 있다. 최근 색상은 앱 실행 중 최대 8개를 공유하며, 기본색과 최근 색상을 클릭하면 즉시 적용한다. 채우기의 첫 칸은 채우기 없음이며, 선과 텍스트의 첫 칸은 흰색이다. 팔레트 상단은 도구 줄 하단에 고정하고, 항목을 바꾸면 포인터만 해당 버튼으로 옮긴다. 세 버튼은 모양으로 구분한다. 선 색은 고리, 채우기는 원, 텍스트 색은 글자 A와 색 막대다. 팔레트가 열린 항목의 버튼은 옅은 보라색 바탕으로 표시한다. 팔레트 머리글 왼쪽에는 항목 이름을, 오른쪽에는 현재 색의 이름과 색상 코드를 표시하고, 색 위에 포인터를 올리면 그 색의 이름으로 바뀐다. 현재 색은 인디고 고리로 표시한다. 팔레트는 뒤의 그림이 흐리게 비치는 반투명 유리 바탕이다. 선은 반듯한 선만 쓰며 손그림 느낌의 선은 제공하지 않는다. `완료`하면 노트로 돌아와 버튼을 누를 때 커서가 있던 자리에 그림으로 들어가고, `취소`하면 노트를 바꾸지 않는다. 노트 안의 다이어그램은 붙여넣은 이미지와 동일하게 이동·크기 조절·배치·삭제·실행 취소를 지원하며([노트 이미지](note-images.md)), 이미지와 다이어그램을 한 번 클릭하면 그림 바깥에 선택 테두리와 여덟 개의 크기 조절 손잡이가 나타난다. 둘 다 상하좌우로 끌어 이동하고 끌고 있는 동안 예상 배치와 주변 본문의 줄바꿈을 표시하고 놓으면 이동을 확정한다. 문단 기준 세로 위치의 저장은 ADR-037을 따른다. 컨텍스트 메뉴는 이미지에서 삭제, 다이어그램에서 편집과 삭제를 제공한다. 더블클릭하면 같은 캔버스에서 다시 편집한다. 다이어그램은 자료 트리에 따로 표시하지 않는다. 그리기와 저장은 코드로 처리하며 AI 공급자를 호출하지 않는다. 자료 트리의 독립 다이어그램 파일, SVG 가져오기, 다이어그램의 분석·과목 정리 반영은 이번 범위에 포함하지 않는다. 화면 흐름은 시안의 C안·① 흐름을, 저장 형식은 ADR-034를, 화살표 설정의 저장은 ADR-036을 따른다.

## LOCAL-P04 · 폴더·원본·삭제

자료 트리의 파일·폴더·과목 루트 행을 우클릭하면 `Finder 열기`를 제공한다. 파일은 Finder에서 실제 보관 파일을 선택하고, 폴더와 과목 루트는 해당 디렉터리를 연다. 앱에서 보고 있던 문서는 유지한다. 보관 파일이 누락된 것으로 표시된 행에서는 이 메뉴를 비활성화한다.

자료 트리는 펼치기·접기·선택을 제공한다. MD는 Markdown 편집기로, PDF는 필기 가능한 PDF 편집기로, 이미지·PPTX는 중앙 미리보기로 연다. PDF 근거 버전은 읽기 전용으로 열며 필기 도구를 제공하지 않는다. 분석 결과 문서는 자료 트리에 자동 생성하지 않는다. 대화에서 만든 정리 제안은 사용자가 `등록`한 경우에만 과목의 `학습도우미 정리` 폴더에 사용자 Markdown 노트로 저장한다. 등록 전 후보·초안은 자료 트리·지도에 넣지 않으며, 등록한 노트는 일반 자료처럼 다음 과목 정리의 대상이 된다. 삭제 전에 대상 이름과 범위를 확인하고 휴지통으로 이동한다. 진행 중이던 자동 저장이 삭제 파일을 다시 만들지 않는다. 자료 삭제는 그 자료의 근거만 제거하며 다른 자료가 뒷받침하는 주장·관계는 유지한다.

현재 중앙에 열린 저장 문서는 트리의 선택 행으로 표시한다. 저장 문서를 우클릭하면 `제목 수정`, `분석`, `꼼꼼하게 다시 정리`를 제공한다. `제목 수정`은 기존 파일명이 표시된 자리에서 바로 편집한다. Enter 또는 다른 곳 클릭으로 적용하고 Esc로 취소한다. 수정 대상은 우클릭한 문서이며 확장자는 유지한다. 한글 입력 조합 중 Enter는 조합을 확정하며 이름 변경을 먼저 실행하지 않는다. 잘못된 이름이나 중복 오류가 나면 입력을 유지하고 같은 자리에서 수정할 수 있다. 저장 파일 하나를 드래그해 같은 과목의 폴더 또는 과목 루트에 놓으면 보관 위치를 변경한다. 변경 후 목적지 폴더를 펼치고 현재 문서의 선택·제목·경로를 동기화한다.

자료 트리의 폴더·과목 루트·빈 영역 우클릭 메뉴는 `새 노트`, `새 폴더` 순서다. `새 노트`는 해당 폴더(빈 영역이면 과목 루트)에 빈 Markdown 파일을 즉시 만들고 중앙에서 연다. 기존 편집 내용 보관에 실패하면 생성·전환을 중단한다. `새 노트.md`가 이미 있거나 기존 문서가 이름을 사용 중이면 `새 노트 2.md`처럼 구분한다. 목적지를 펼치고 새 문서를 선택하며 중앙 제목을 편집 상태로 연다. Enter로 제목을 적용하고 본문으로 이동, 본문 클릭으로도 적용, Esc로 기본 제목을 유지한다. 한글 조합 중 Enter/Esc는 제목 명령으로 처리하지 않는다. 제목 오류 시 입력을 유지하고 재입력한다. 경로는 중앙 상단에 표시한다. 이 문서는 `작성 중`에 중복 표시하지 않으며 빈 상태에서도 전환·재실행 후 유지한다. 이후 편집은 자동 저장하고 ⌘S로 저장 위치를 다시 묻지 않는다. `작성 중`은 아직 파일로 저장하지 않은 초안만 뜻한다.

자료 트리의 우클릭 메뉴에서 `새 폴더`를 만든다. 폴더 또는 과목 루트에서 실행하면 그 안에, 빈 영역에서 실행하면 과목 루트에 만든다. 파일을 우클릭한 메뉴에는 `새 폴더`를 표시하지 않고 `제목 수정`, `분석`, `꼼꼼하게 다시 정리`를 제공한다. 입력 창에 생성 위치를 표시한다. 생성 후 새 폴더까지 펼치고 위치를 보여 주며 열린 문서는 유지한다. 중복되거나 잘못된 이름은 기존 파일·폴더를 변경하지 않고 오류를 알리며 다시 입력하거나 취소할 수 있다.

파일 종류는 PDF 문서·PPTX 슬라이드·이미지·Markdown 아이콘으로 구분한다. Markdown 이외 파일에는 실제 파일명에서 읽은 확장자 배지를 표시한다. 긴 제목이 줄어들어도 배지를 유지하고, JPG/JPEG 등 실제 확장자를 구별한다. 파일 종류와 누락 여부는 접근성 이름에도 제공한다. 자료 트리에는 파일별 분석 상태를 상시 표시하지 않으며, 과목 정리의 `정리 필요`·`정리 품질 낮음`은 LOCAL-P10에 따라 표시한다. 파일 제목에 기본 툴팁을 표시하지 않는다. 중앙 본문 제목 오른쪽에 `분석완료`는 초록색, `분석 미완료`는 회색 헬퍼 텍스트로 표시한다. 미분석·갱신 필요·미저장 변경은 분석 미완료로 표시한다. 작성 중인 미저장 초안에는 같은 위치에 노란색 `작성중`을 표시한다. 과목 미선택·지도·분석 당시 원본 화면에는 이 헬퍼를 표시하지 않는다. 상세 상태는 자료 트리 접근성 이름에 유지한다. 현재 해시와 일치하는 분석 결과가 있을 때만 `분석됨`이며, 분석 중 상태는 별도로 표시한다.

제목·위치 변경 전에 현재 편집 내용을 저장하며 저장 실패 시 변경을 중단한다. 같은 이름의 파일을 덮어쓰지 않는다. 변경 후에도 문서 ID·본문·분석 근거와 불변 원본은 유지한다. 외부 파일 드래그 가져오기, 폴더 이름·위치 변경, 과목 간 이동, 복수 선택·일괄 이동은 이번 적용 범위에 포함하지 않는다. 오르카 조사 근거와 네이티브 적용 차이는 자료 트리 상호작용에 기록한다. 이 정책 추가는 구현·실기 검증 통과를 뜻하지 않는다.

## LOCAL-P05 · 가져오기와 명시적 분석

`자료 추가하기`에서 파일과 보관 폴더를 선택하면 과목의 작업 폴더에 보관하고 자료 트리에 등록한다. 가져오기만으로 분석을 시작하지 않으며 공급자 연결·전송 동의를 요구하지 않는다. PDF·PPTX·이미지·Markdown과 PPTX에서 만든 PDF에 같은 규칙을 적용한다.

분석은 사용자가 자료 탭의 `정리 제안` 창 우측 상단에서 `전체 정리`를 누르거나 자료 트리의 파일 우클릭 메뉴에서 `분석`을 명시적으로 선택할 때 시작한다. `과목 정리`는 새 자료·바뀐 자료를 읽고 개념 맞추기·잇기로 과목 지도를 만든다. 새로 읽을 자료가 없으면 맞추기·잇기만 다시 한다. 저장한 노트도 대상이며 파일별 `분석`은 그 자료 하나만 읽는 보조 경로로 남긴다. 현재 파일과 일치하는 분석을 마친 자료에서는 `분석` 메뉴를 보이되 비활성화하고, 미분석·갱신 필요 자료에서는 활성화한다. 진행 중에는 중복 분석을 시작하지 않으며 LOCAL-P07의 실행 순서를 따른다. 필기·편집·가져오기는 분석이나 과목 정리를 자동 실행하지 않는다. `꼼꼼하게 다시 정리`는 선택한 자료만 가장 높은 등급으로 다시 읽는다.

요청 시 대상 파일의 미반영 편집·필기를 먼저 저장한 뒤 입력 해시와 분석 당시 사본을 고정한다. 저장 실패 시 분석을 시작하지 않는다. 분석 중에도 해당 파일을 편집·필기할 수 있다. 그 사이 파일 해시가 바뀌면 완료 결과를 지도에 반영하지 않고 기존 지도를 보존하며 다시 요청하도록 안내한다. 실패·취소에도 작업 파일과 기존 지도를 보존한다. 같은 자료·버전의 분석 결과는 그래프에 중복 반영하지 않는다.

## LOCAL-P06 · 구독 연결과 전송 고지

파일별 분석 요청 시 Codex·Claude·Antigravity 중 공급자를 선택하고 선택을 기억한다. 최초 전송 전에 안내를 제공하며 가져오기·열기·필기에는 연결을 요구하지 않는다. 설치·인증·실제 분석 성공은 서로 다른 상태다. 설치된 공식 실행 파일을 먼저 사용하며 없으면 선택한 공급자의 공식 설치 절차를 안내·시작한다. 공급자 실행 파일을 앱에 기본 내장하지 않는다. Codex는 공식 app-server 로그인 흐름, Claude는 공식 인증 명령을 사용한다. 토큰 저장·갱신은 해당 공식 도구가 담당한다.

연결 화면과 가이드에는 **선택한 자료의 추출 텍스트와 필요한 원본 이미지가 선택한 구독 공급자에게 전송된다**고 명시한다. 구독 연결 실패를 API 과금으로 자동 전환하지 않는다. 사용자 인증·승인 입력이 필요하면 실제 사용자가 수행하며 완료를 관찰하기 전에는 인증 성공으로 기록하지 않는다.

`과목 정리`는 확인 창에 대상 목록·보낼 공급자·정리 방식과 예상 호출 수·사용량을 알린 뒤 시작한다. 자료 읽기는 PDF 파일째가 아니라 쪽별 글과 쪽 이미지를 보낸다. 개념 맞추기는 후보 개념의 이름·정의·근거 문장 한 줄씩, 개념 잇기는 과목 개념 사전의 이름·정의·유형과 기존 연결을 보내며 원문은 보내지 않는다. 연결 검수는 점선 연결과 양쪽 개념의 정의·근거 문장을 보낸다. 과목별 정리 지침은 자료 읽기·맞추기·잇기의 지시문에 덧붙인다.

학습도우미는 사용자가 입력한 텍스트, 사용자가 직접 첨부한 이미지, 해당 공급자 세션의 이전 대화 문맥만 전송한다. 과목 선택·문서 열기만으로 파일을 전송하지 않는다. Codex/Claude/Antigravity의 대화와 세션은 과목별로 분리한다. 연결 상태와 실제 대화 성공은 구분한다.

대화 정리는 고른 질문·답 묶음, 과목 개념 이름과 기존 제안·등록 노트 제목을 같은 대화를 나눈 공급자에게 별도 호출로 다시 보낸다. 대화 전체나 자료 원문은 보내지 않고 채팅 세션 문맥에도 섞지 않는다. 처음 강한 정리 신호가 생기면 `이번만 정리`·`앞으로 중요한 것만 알아서`·`괜찮아요`를 한 번 묻고, 재전송과 구독 사용량 소비를 함께 알린다. `끔`·`물어보고`에서는 뒤에서 모델을 부르지 않으며 `중요한 것만 알아서`에 동의한 경우에만 강한 신호를 자동 정리한다.

Antigravity는 공식 `agy acp`를 사용하며 개인 Google 계정 OAuth만 제공한다. 무료·Google AI 구독의 실제 이용 가능 모델과 한도는 공급자가 결정한다. Stology 전용 CLI 홈에서 로그인과 세션을 관리하므로 터미널의 기존 로그인과 별도로 연결할 수 있다. API 키·Vertex/기업 과금으로 전환하지 않으며 추가 AI 크레딧 사용을 켜지 않는다. 계정에서 조회한 버전 모델과 모델별 사고 수준만 표시한다. ACP 모델 ID가 내부 식별자이면 CLI가 제공한 버전 이름을 표시한다. 채팅 이미지와 자료 분석 이미지는 ACP 인라인 입력으로 전달한다. 설치·인증·추론 성공을 각각 구분한다. ADR-022를 따른다.

## LOCAL-P07 · 작업·오류·격리

파일별 분석과 과목 정리는 같은 작업 실행기를 사용하고 채팅 턴과 실행의 각 단계는 같은 실행 잠금으로 앱 전체에서 한 번에 하나만 실행한다. 작업 ID·입력 해시·묶음 버전·스킬 버전·지시문 지문·공급자·요청 등급·실제 모델과 effort를 기록한다. 앞줄은 채팅과 사용자가 요청한 정리, 뒷줄은 대화 정리다. 채팅이 오면 과목 정리는 지금 단계가 끝난 뒤 양보하고 `정리 멈추고 바로 질문`을 제공한다. 뒷줄 작업은 취소 후 다시 줄에 넣는다. 뒤에서 쓰는 양은 `적게` 하루 5번·`보통` 20번·`넉넉하게` 50번으로 제한한다.

진행·취소·최종 성공·실패를 구분한다. 실행 계획과 단계 상태는 `<데이터 폴더>/ai/runs/<id>/run.json`, 끝난 단계 결과는 `ai/cache/`에 입력 해시·스킬 지문·공급자·모델·effort를 키로 보관해 재사용한다. 앱 종료 시 진행 단계만 취소하고 자식 프로세스를 회수한다. 다시 열면 자동 실행하지 않고 `이어서 정리`로 남은 단계부터 실행한다. 유휴 상태에는 AI 프로세스를 상주시키지 않는다. 전용 작업 디렉터리를 사용하고 사용자 프로젝트 규칙·훅·MCP·설정의 영향을 차단한다. 읽기 전용이라는 이유만으로 모든 도구가 비활성이라고 판단하지 않는다.

앱 내장 스킬은 실행기가 읽어 공급자 호출의 지시문에 넣으며 공급자 CLI의 스킬 기능을 켜지 않는다. `AI 설정`에서 정리 방식(`알아서`·`빠르게`·`꼼꼼하게`)과 단계별 모델을 고른다. `빠름`·`균형`·`정밀` 등급은 계정의 모델 목록과 공급자별 규칙으로 실제 모델에 대응하고, 없는 등급은 가장 가까운 아래 등급으로 내려 확인 창에 알린다. 맞추기·잇기의 최저 등급도 없으면 점선 연결 없이 단원 묶기까지만 한다. 고급의 `스킬 폴더 열기`는 `<데이터 폴더>/ai/skills/`에 사용자 사본을 만들고, 사본이 있으면 지시문과 `routing.json` 값을 사용한다. 스키마와 코드 검증은 고정한다. `기본값으로 되돌리기`는 사본을 `ai/skills-이전-<시각>`으로 옮긴다. 고친 스킬 사용과 단계별 호출 수·등급·실제 모델·다시 읽은 이유는 `어떻게 정리했나요`에 표시하며 공급자가 반환한 토큰 수만 함께 표시한다. 남은 구독 한도와 초기화 시각은 추정해 표시하지 않는다.

만료 인증·구독 한도·네트워크·손상 파일·암호화·지원하지 않는 형식·잘못된 JSON·근거 검증 실패를 사용자에게 구체적으로 알린다. 실패를 빈 지도 생성 성공으로 취급하지 않는다. 근거 대조에서 버린 주장 비율이 기본 0.3을 넘거나 형식 오류·빈 결과이면 해당 쪽 묶음을 한 등급 올려 한 번 다시 읽는다. 다시 해도 기준을 넘거나 이미 가장 높은 등급이면 `정리 품질 낮음`으로 표시한다. 유효한 자료 결과를 만들지 못한 자료는 건너뛰고 이유를 남긴다. 연결 탈락률이 기준을 넘으면 가장 높은 등급으로 한 번 다시 잇고, 그래도 넘으면 그 개정에 점선 연결을 넣지 않는다. 맞추기·잇기 실패는 이전 과목 지도를 유지한다. 이 검사 외 재시도는 사용자가 요청할 때 한다. 한도 오류이면 과목 정리는 멈춘 상태로 남기고 뒷줄은 그날 멈춘 뒤 한 번 알리며, 다른 모델·공급자나 API 과금으로 자동 전환하지 않는다. 기술 경계는 ADR-026을 따른다.

채팅은 수락·실제 텍스트 증분·완료·중단·실패를 구분한다. 중지 시 부분 답변을 남기고, 비정상 종료의 미완료 턴은 중단으로 복구한다. 세션 재개 실패를 새 세션으로 숨기지 않는다. 저장 실패는 보존 완료로 표시하지 않고 복사·저장 재시도를 제공한다. 미보존 답변이 있으면 종료를 보류한다.

## LOCAL-P08 · 지원 자료와 한계

지원 범위는 PDF, MD, PNG, JPEG, HEIC, PPTX다. `.ppt`는 지원하지 않는다. PDF 필기는 텍스트 하이라이트·영역 하이라이트·박스·메모·펜과 선택·이동·크기 변경·삭제·실행 취소/다시 실행을 대상으로 한다. 도구는 아이콘으로 표시하고 모든 도구에 버튼 위의 짧은 호버 말풍선과 접근성 이름을 제공한다. 설명은 한 번만 표시하며 기본 툴팁이나 별도 설명 줄을 중복 표시하지 않는다. 빈 점선 사각형의 영역 선택 도구는 화면에서 드래그한 사각형에 완전히 포함된 앱 필기를 여러 페이지에 걸쳐 선택한다. 선택한 필기는 Delete·백스페이스 또는 휴지통으로 한꺼번에 삭제하고, 일괄 삭제는 한 번의 실행 취소·다시 실행 단위로 처리한다. 메모 글 편집 중에는 문자 삭제를 유지한다. 메모 편집 완료 시 저장할 주석과 선택 영역을 텍스트 크기에 맞춘다. 박스·영역 생성은 드래그로만 확정하고 클릭만으로 점 주석을 만들지 않는다. PDF 본문이나 PowerPoint 객체 편집, PDF 필기의 PPTX 역변환은 범위 밖이다. PDF는 페이지별 텍스트와 스캔 페이지 OCR을 사용하고 필요한 페이지 이미지를 함께 분석한다. 이미지는 시스템 디코딩·OCR·실제 이미지 입력을 함께 사용한다. PPTX는 슬라이드 순서·본문·발표자 노트·표·내장 이미지를 추출한다. 복잡한 SmartArt·도형 배치의 완전한 해석은 보장하지 않고 PDF 입력을 안내한다. 추출·이미지 캐시는 내부에 저장하고 크기를 제한한다. OCR 텍스트만으로 이미지 이해를 통과 판정하지 않는다.

PPTX 시스템 미리보기가 내용을 표시하지 못할 수 있다. 이미 설치된 LibreOffice가 있으면 내부 캐시 PDF로 변환해 중앙에서 표시하고 변환 미리보기라고 알린다. 원본은 보존하며 앱에 변환기를 포함하거나 자동 설치하지 않는다. 미설치·실패 시 PDF 입력을 안내한다. 변환 중에도 취소·제한 시간과 프로세스 회수를 적용한다.

PPTX에서 필기를 시작하면 실제 PPTX 부모 폴더에 편집용 PDF를 생성하고 별도 문서 ID의 미분석 자료로 등록한다. 같은 이름의 기존 PDF를 덮어쓰거나 관련 파일로 추정하지 않으며 번호를 붙여 새로 만든다. 원본 PPTX ID와 연결한 PDF만 재사용한다. 이름·위치 변경 뒤에도 연결을 유지하고, PPTX가 바뀌어도 기존 필기 PDF를 자동 재변환하지 않는다. PPTX 삭제 후 PDF는 독립 자료로 남으며 PDF 삭제 시 연결을 해제한다. 원본 PPTX는 자동 삭제하지 않는다.

분석 제한(100 MiB·100쪽)은 필기 가능 범위와 별개다. 현재 PDF 저장은 256 MiB 한도를 두며 초과하면 교체 전에 거부하고 기존 파일·미반영 기록을 보존한다. 필기로 파일이 커져 분석 제한을 넘으면 분석 요청 시 구체적으로 알린다. 필기한 PDF는 요청 시점 파일 그대로 추출하며, 주석 외형·메모 텍스트가 실제 추출 이미지·글에 포함되는 범위는 PDF 검증 기록에서 구분한다.

분석은 연속한 쪽을 기본 최대 24쪽(이미지 24장)의 묶음으로 고르게 나누어 실행한다(27쪽은 14+13쪽). 묶음 경계에서 겹쳐 읽지 않고 자료 전체의 쪽 번호를 유지한다. 묶음마다 한 번 호출하고 모든 묶음이 끝난 뒤 자료 단위로 합쳐 한 번 반영한다. 다시 읽어도 실패한 묶음이 있으면 해당 자료는 반영하지 않으며, 끝난 묶음은 보관해 다음 요청에 재사용한다. 묶음 크기는 `routing.json`에서 조절하되 지원 파일·용량 제한과 구분한다.

## LOCAL-P09 · 근거가 있는 지식

불변 원본과 지식 저장·지도 표시를 구분하고, 지식은 자료가 말한 아래층과 과목 정리 위층의 두 층으로 나눈다. 아래층은 기존 `concepts`·`relations`·`assertions`·`sources`·`supports`를 유지한다. 위층은 아래층과 사용자 교정으로 다시 만들 수 있는 파생 보기이며 `ont_*` 표에 개정·대표 개념 덮어쓰기·합친 기록·단원·정리하며 이은 연결·자료별 정리 상태를 둔다. 사용자 소유의 숨긴 연결·`다른 개념` 교정·과목별 정리 지침은 재정리해도 유지한다. 첫 마이그레이션 때 `knowledge.before-subject-layer.sqlite` 사본을 남긴다. 아직 과목 정리를 하지 않은 과목은 기존 아래층을 그린다.

불변 원본은 명시적 분석·과목 정리에서 읽기를 요청한 버전에만 보관한다. 가져오기·열기·지도 조회·Markdown 저장·PDF 필기 저장은 새 불변 원본 사본을 만들지 않는다. 기존 사본·근거는 자동 삭제하지 않는다. PPTX에서 생성한 PDF는 독립 분석 자료이며 원본 PPTX의 발표자 노트 등 분석 결과를 이식하지 않는다. 원본 버전은 자료 ID·내용 해시·페이지/슬라이드/문단/이미지 위치를 보존한다. 개념에는 안정적인 ID·대표 이름·별칭·짧은 문맥 정의와 유형(개념·원리/법칙·공식·절차/방법·사례·인물/사건)을 둔다. 아래층 관계의 연결어·의미·방향·동의 표현과 주장의 조건·부정을 보존한다. 근거에는 실제 원문 위치와 인용 또는 이미지 영역을 연결한다.

자료별로 추출한 주장의 위치·인용을 Rust에서 대조하되 공백 차이는 허용한다. 틀린 주장만 버리고 탈락 비율로 LOCAL-P07의 다시 읽기를 판단한다. 같은 과목 안에서 이름·별칭으로 후보를 좁혀 정의·근거를 비교하고 `같음`인 경우만 합치며 `다름`·`모름`은 합치지 않는다. 합친 기록을 남겨 되돌릴 수 있게 하고 동명이의어·원인과 상관관계·조건부와 무조건 주장을 구분한다. 충돌하는 자료의 출처·조건을 각각 보존한다.

과목 층의 연결 유형은 종류(`kind_of`)·구성(`part_of`)·선행(`prerequisite`)·원인(`cause`)·대조(`contrast`)·예시(`example`)·적용(`applies`)·관련(`related`) 여덟 가지다. 자료에 적힌 연결은 실제 근거가 있는 실선, 정리하며 이은 연결은 이유가 있는 점선으로 구분한다. 단순 동시 등장이나 모델 배경지식을 자료에 적힌 사실로 저장하지 않는다. 없는 개념·자기 연결·허용하지 않은 유형·종류와 선행의 순환·개념당 상한 초과를 검사한다. `꼼꼼하게` 방식은 점선 연결을 추가 검수해 뒷받침되지 않는 것을 버린다. 검사는 형식과 근거의 실재를 확인할 뿐 의미의 정확성을 보장하지 않는다.

새 과목 개정은 작업용 사본 DB에서 만든 뒤 자료 해시와 과목 세대 번호가 그대로일 때만 한 트랜잭션으로 교체한다. 자료 변경·취소·실패에서는 이전 지도를 유지한다. 저장·분할 경계는 ADR-027을 따른다.

## LOCAL-P10 · 버전·갱신·지도 탐색

분석 당시 불변 원본과 현재 작업 파일을 구분한다. Markdown 편집과 PDF 필기는 모두 본문 변경이며 파일 해시와 문서 버전을 갱신한다. 분석한 파일을 편집·필기하면 구버전 근거와 갱신 필요 상태를 표시하며 자동 재분석하지 않는다. 근거는 분석 당시 사본을 읽기 전용으로 열고 현재 파일로 바꿔 보여 주지 않는다. 사용자가 요청한 재분석만 새 버전으로 반영한다. 지도에는 회전·줌·초점·전체 보기·검색·노드 목록·실제 관계 사전 기반 필터·임시 드래그·선택 해제를 제공한다. 노드 선택으로 출처를 확인하며 간선은 선택하지 않는다. PDF는 해당 페이지, MD는 해당 구절로 이동한다. PPTX는 원본 미리보기와 슬라이드 번호를 제공하되 공개 API가 지원하지 않는 슬라이드 직접 이동을 표시하지 않는다. 정지·백그라운드에는 불필요한 렌더링을 중지하고 반복 열기·닫기 후 메모리를 회수한다.

기존 지도와의 동등성에는 실제 xyz 원근·깊이 picking, 제한된 pitch의 궤도 회전, 휠/핀치/버튼/키 줌, 카메라 평면 임시 드래그 후 복원, 탭/드래그 구분, 빈 공간/Esc 선택 해제, 더블탭·0·R 전체 보기, 선택+1홉 초점과 패널 여백, hover, ⌘K 및 검색 키보드 탐색, 노드 목록 정렬·더 보기, 선택 개념의 관계 라벨/개수/정의 기반 이웃 강조, 관련 개념 재초점, 과목별 탐색 상태 복원, 동작 줄이기와 렌더 수명주기를 포함한다. 관계 필터를 전역 간선 숨김만으로 대체하지 않는다. 학습 상태·주차·팀 표시는 포함하지 않는다. 세부 독립 판정은 QA-LOCAL-065~080을 따른다.

자료를 고치면 문서 제목 옆에 `정리 필요`를 표시하며 사용자가 다시 정리할 때만 갱신한다. 검사 후 기준을 넘는 자료는 `정리 품질 낮음`으로 표시하고, 그런 자료에서만 나온 개념 카드에도 이 상태와 `꼼꼼하게 다시 정리`를 제공한다. 과목 지도에는 단원 → 개념 목록·단원별 색과 초점, 여덟 연결 유형 필터를 제공한다. 개념 카드에서 정의·유형·문장으로 읽히는 연결·점선의 이유와 `이 연결 숨기기`, `합쳐진 이름 보기 · 되돌리기`를 제공한다. 숨긴 연결과 `다른 개념` 교정은 다음 정리에서도 유지한다. 개념 카드에서 잘린 연결 문장은 첫 클릭으로 펼치고 다시 클릭하면 상대 개념으로 이동한다. 연결 행을 우클릭하면 영구 삭제할 수 있다. 확인 후 해당 연결과 전용 근거를 함께 삭제하고 재정리에서도 같은 방향·유형·조건·부정 여부의 연결을 제외한다. 원본 자료와 양끝 개념은 보존한다. 개념 카드의 설명 문장은 클릭해 그 자리에서 고칠 수 있다(Enter 저장·Esc 취소, 200자 이내). 고친 문장 아래에는 편집할 수 없는 연한 글씨로 `(수정됨)`을 표시하고 `되돌리기`로 자료에서 정리한 원래 문장으로 돌린다. 고친 문장은 다시 정리해도 덮어쓰지 않는다. `배운 곳`은 정리 당시 원문 위치로 이동하고 등록한 대화 노트는 `내 질문에서`로 구분한다.

지도에서 자료 추가 버튼 왼쪽의 빗자루를 누르면 확인 창이 열린다. 사용자가 `검토 시작`을 선택하면 AI가 현재 과목 전체의 삭제 후보를 검토한다. 채팅 답변 생성, 자료 분석·과목 정리, 대화 노트 생성, 삭제 후보 검토가 진행되는 동안 중앙 하단 상태 문구 옆에 회색 스피너를 표시한다. 사용자가 후보 이름과 제안 이유를 읽고 여러 개를 선택하거나, 지도 노드를 우클릭해 직접 삭제할 수 있다. 두 흐름 모두 승인 전에 선택한 노드와 연결이 모두 사라질 이웃을 표시한다. 숨긴 연결도 의존 관계에 포함한다. 이웃은 기본으로 남겨 두며 사용자가 체크한 경우만 함께 삭제한다. 승인 뒤 삭제한 개념과 그 구성원·연결을 정리하고, 같은 개념 ID는 자료를 다시 읽어도 복원하지 않는다.


## LOCAL-P11 · 저장·배포·제외

앱 전용 Application Support에 실제 .md·작업 파일·SQLite를 둔다. PDF 필기의 정본은 본문과 편집 가능한 주석을 담은 작업 PDF 하나이며 같은 경로를 자동 갱신한다. 외부 Downloads/e-Class 원본을 자동으로 찾아 덮어쓰지 않는다. 필기를 위해 깨끗한 원본·전체 필기 DB·저장별 PDF 사본을 영구 중복 보관하지 않는다. 복구 기록은 아직 PDF에 반영하지 못한 변경만 보관하고 반영 확인 후 정리한다.

다이어그램 제목은 노트 제목과 같은 입력란과 편집 규칙을 사용하며 기본값은 `제목 없음`이다. 제목은 그림 내용에서 추출하지 않는다. 캔버스에 그린 내용이 있으면 `완료`로 제목과 그림을 함께 저장한다. 빈 캔버스에서 완료하면 노트로 돌아가며 새 첨부를 만들거나 기존 그림을 덮어쓰지 않는다.

노트 다이어그램의 정본은 제목·그림·편집 데이터를 함께 담은 SVG 한 파일이며 과목 `files`의 숨김 폴더 `.diagram`에 둔다. 노트는 표준 Markdown 이미지 문법으로 참조하고 다시 편집하면 같은 파일을 교체한다. `.diagram`은 자료 트리와 저장 위치 선택에 표시하지 않는다. 노트에서 그림을 지워도 파일은 남긴다.

화면 반영·복구 기록·PDF 저장 상태를 구분한다. 복구 기록만 완료됐으면 `저장 중`이며, 파일 게시와 문서 버전 정합 확인까지 끝나야 `PDF에 저장됨`으로 표시한다. ⌘S·공유·분석·정상 종료는 최신 변경의 PDF 반영을 기다린다. 저장 실패·외부 변경 충돌에서는 원본 PDF와 미반영 기록을 보존하고 오류를 표시하며 조용히 덮어쓰거나 완료로 표시하지 않는다. 충돌한 내용은 사용자의 별도 PDF 저장 또는 명시적인 변경 폐기·다시 열기로 해결한다. 삭제한 PDF를 지연 저장으로 되살리지 않는다. 강제 종료 시 저널에 커밋된 변경까지 복구하며 커밋 전 입력·정전까지 무손실을 보장하지 않는다.

파일 교체와 저장 버전 확인으로 게시 경합을 처리한다. Apple Silicon .app과 .dmg는 본인 Mac 테스트용 서명 빌드이며 Apple 공증 완료 배포본으로 표시하지 않는다. 학습 완료·예정·숙련도, 팀, 퀴즈, 리포트, 클라우드 동기화는 범위 밖이다. 기존 웹·백엔드는 수정하지 않는다.

## LOCAL-P12 · 검증·기술 선택

동일 디자인·한글 편집·원본 미리보기·지도 조작을 통과한 release 네이티브와 Tauri/WKWebView 비교판을 같은 Mac·자료로 반복 측정한다. 웹이 전체 관련 프로세스 메모리 중앙값을 10% 이상 줄이고 실행 시간·입력/프레임 지연·유휴 CPU·설치 크기를 악화시키지 않으면 웹으로 전환한다. 그 외에는 네이티브를 유지한다. 비교 자격을 충족하지 못하면 우위를 확정하지 않는다. 편집 정확성과 시각 품질은 낮추지 않는다. 측정 환경·규모·빌드·AI 프로세스 포함 여부를 함께 기록한다. 자동 테스트와 실제 계정·앱 검증을 구분하고 실제 관찰이 없는 항목은 통과로 쓰지 않는다.

학습도우미는 검색창 왼쪽에 대화 목록 아이콘을 표시한다. 아이콘을 누르면 흰색 유리 시트가 검색창 뒤에서 그라데이션으로 이어지며 내려오고, 다시 누르면 닫힌다. 목록에 여러 항목이 있으면 하단 손잡이로 높이를 조절할 수 있다. 드래그가 마지막 카드의 세로 중앙에 닿으면 카드 전체를 표시하고, 중앙에 못 미치면 앞 카드에서 시트를 끝낸다. 높이는 현재 검색 결과의 전체 높이와 입력창 위 여유 공간을 넘지 않는다. 조절한 높이는 현재 창에서 다시 열 때도 유지한다. 목록에는 첫 질문(전송 전에는 초안)을 이름으로 표시하고 현재 대화·공급자·날짜를 함께 보여 준다. 동작 줄이기에서는 즉시 전환한다. 대화 검색은 현재 워크스페이스의 질문·답변·초안을 모든 공급자에 걸쳐 조회한다. 새 대화에서는 현재 대화를 보관하거나 앱 기록을 삭제할 수 있다. 보관한 대화를 열면 기존 CLI 세션 ID와 초안을 복원한다. CLI 자체 기록과 별도로 저장된 제안·등록 노트는 유지한다. 대화에서 새 노트 제안을 만드는 범위는 포함한다. `나중에 정리`는 표시를 남기고, `노트로 정리`는 지금 초안을 만들며, `그대로 저장`은 모델 호출 없이 질문·답을 저장한다. 자동 정리는 반복 질문·사용자 표시·과목 개념이 나오는 연속 질문 같은 강한 신호만 대상으로 하고, 약한 신호는 모델을 부르지 않은 후보로 남긴다. 짧거나 중지·실패한 답, 과목과 무관한 작업 요청, 이미 등록한 내용과 표시 없는 일회성 질문은 자동 호출하지 않는다.

`끔`·`물어보고`·`중요한 것만 알아서`와 최초 동의는 LOCAL-P06을 따른다. 제안은 `자료` 탭 파일 검색 옆 ✦ 버튼에서 여는 `정리 제안` 창에 모은다. 제목 옆에는 제안 수를 `3개`처럼 제목보다 작은 회색 글자로 표시한다. 제안은 `초안`·`AI 초안`·`정리 전` 꼬리표로 구분한다. 초안은 `등록`·`수정`·`삭제`를, 정리 전 후보는 `초안 만들기`·`삭제`를 제공하며 삭제는 창 안에서 한 번 더 확인한다. 초안의 `수정`을 누르면 중앙 노트 편집기에 제목과 본문이 열리고, 변경 사항은 제안에 자동 저장된다. 편집기에서 `등록`을 누르면 학습도우미 정리 폴더에 저장된다. 등록 전에는 자료·지도에 반영하지 않는다. `새 대화` 전에는 정리 대상 턴의 스냅샷을 보관하며 삭제한 제안의 스냅샷은 지운다. 걸러 내기·방식·동의와 저장 경계는 ADR-028을 따른다. 대화 내보내기, 이미지 외 파일 첨부·자동 읽기·기존 노트 수정·셸·웹·MCP 도구 실행은 계속 제외한다.

AI 설정은 단일 라벤더 모달 패널로 열고 전환 탭과 닫기 버튼을 같은 패널 안에 둔다. 오른쪽 상단의 사이드바와 같은 알약 탭으로 `정리 방식`·`도우미 설정`을 전환하며, 도우미별 설명과 모델 선택은 반투명 카드에 표시하고 닫기는 오른쪽 아래에 둔다.

도우미 설정의 왼쪽 메뉴는 `직접 선택`과 `Codex / Plus`·`Codex / Pro`·`Claude / Pro`·`Claude / Max`·`Claude / Ultra` 추천 프리셋을 제공한다. 프리셋은 사용자가 고르는 앱 추천값이며 계정 요금제 자동 감지나 한도 보장이 아니다. Plus·Claude Pro는 정밀 요청을 균형으로 낮추고, Codex Pro·Claude Max는 정리 방식의 등급을 유지하며, Claude Ultra는 활성 단계에 정밀 등급을 추천한다. 실제 CLI 목록에서 가능한 모델로 해석한다. 연결 검수는 기존처럼 꼼꼼하게 방식에서만 실행한다. 직접 선택에서는 도우미별로 공급자와 모델을 혼합할 수 있고, 프리셋 전환 중에도 직접 선택 조합을 보관한다. 조회 실패 공급자는 안내하고, 목록에서 사라진 저장 모델을 조용히 다른 모델로 교체하지 않는다.

노트 제목과 본문은 독립적으로 저장한다. 새 초안은 사용자가 제목을 입력하기 전까지 `제목 없음`을 유지하며 본문에서 제목을 추출하지 않는다. 기존 제목도 본문 편집으로 변경하지 않는다.

앱에서 설정하는 macOS 기본 툴팁은 표시하지 않는다. PDF 필기 도구의 별도 호버 말풍선은 유지한다.
