# Stology Local · 시작하기

이 설치본은 Apple Silicon Mac에서 본인이 테스트하기 위한 ad-hoc 서명 빌드입니다. Apple 공증 완료 배포본이 아닙니다.

1. `Stology Local.app`을 옆의 `Applications` 폴더로 옮깁니다.
2. Applications에서 앱을 엽니다. macOS가 실행을 막으면 앱 출처를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 열기 허용을 사용합니다.
3. 왼쪽에서 과목을 만들고 중앙에 작성합니다. 첫 저장에서는 제목·폴더를 고릅니다. 이후 편집은 자동 저장됩니다.
4. 구독 계정 연결에서 Codex 또는 Claude를 선택하고 공식 도구로 로그인합니다. 자료 분석에 필요한 텍스트·이미지는 선택한 공급자에게 전송됩니다. API 과금으로 자동 전환하지 않습니다.
5. 지식지도 펼치기 → 자료 추가하기로 원본을 보관·분석합니다. 저장한 노트를 분석해도 원본을 중복 생성하지 않습니다.

[오프라인 가이드북 열기](가이드북/index.html) · [단축키와 Markdown 입력표](가이드북/assets/keyboard-shortcuts.html)

링크를 지원하지 않는 텍스트 뷰어라면 이 디스크 이미지 안의 `가이드북` 폴더에서 `index.html`을 여세요. 설치 뒤에는 앱의 도움말 → 오프라인 가이드북으로 열 수 있습니다. 앱 패키지의 `Contents/Resources/guide/index.html`에도 같은 가이드가 있습니다.

기본 자료 위치는 `~/Library/Application Support/Stology Local/`입니다. 백업하려면 앱과 분석을 종료한 뒤 이 폴더 전체를 보관하세요.

PPTX는 이미 설치된 LibreOffice가 있으면 내부 PDF로 변환해 미리봅니다. 변환기를 앱에 포함하거나 자동 설치하지 않습니다. 없으면 시스템 Quick Look을 사용하며 파일에 따라 내용을 표시하지 못할 수 있습니다. 실패할 때는 PDF로 내보내 다시 입력하세요. 원본 PPTX는 유지됩니다.

실제 검증한 내용과 남은 제한은 가이드의 검증 기록을 확인하세요. 설치 성공과 모든 제품 QA의 완료는 다릅니다.
