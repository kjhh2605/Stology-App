# Stology Local 단축키와 Markdown 입력

기준: 2026-11-16 · macOS 로컬 앱의 현재 구현.

`⌘`는 Command, `⌥`는 Option, `⇧`는 Shift입니다. `Space`는 공백 키입니다. 편집 단축키는 본문에 커서를 놓고 사용합니다.

## 자주 쓰는 단축키

| 동작 | 단축키 | 사용 방법 |
| --- | --- | --- |
| 2×2 표 삽입 | ⌘⇧A | 본문에 머리행을 포함한 빈 표 삽입 |
| 새 노트 | ⌘N | 새 초안을 열고 본문으로 이동 |
| 저장 | ⌘S | 첫 저장은 제목·폴더 선택, 이후에는 현재 노트 저장 |
| 실행 취소 | ⌘Z | 직전 편집 취소 |
| 다시 실행 | ⌘⇧Z | 취소한 편집 다시 적용 |
| 잘라내기 | ⌘X | 선택한 내용 잘라내기 |
| 복사 | ⌘C | 선택한 내용 복사 |
| 붙여넣기 | ⌘V | 클립보드 내용 붙여넣기 |
| 모두 선택 | ⌘A | 일반 본문에서는 전체 문서 선택 |
| 선택 영역 확장 | ⌘D | 반복해서 단어 → 괄호·인용·서식 → 문장·줄 → 문단·블록 → 전체 문서로 확장 |
| 학습도우미에게 묻기 | ⌘L | 노트에서 고른 블록을 학습도우미 다음 질문에 붙임. 고른 블록이 없으면 붙이지 않음 |
| 앱 종료 | ⌘Q | 저장 처리를 거쳐 앱 종료 |

코드 블록 안에서 ⌘A를 누르면 해당 블록의 코드 내용만 선택합니다. 반복해도 같은 코드 블록에 머뭅니다. 코드 밖이나 여러 블록에 걸친 선택에서는 전체 문서를 선택합니다.

⌘D는 현재 선택을 포함하는 가장 작은 범위부터 확장합니다. 해당 구조가 없으면 그 단계를 건너뜁니다. 코드 안에서도 단어·괄호·줄·블록을 선택하며, 내용을 변경하거나 실행 취소 기록을 만들지 않습니다. 한글 조합 중에는 선택을 바꾸지 않습니다. 커서를 옮기거나 직접 선택하면 그 위치에서 다시 확장합니다. [IntelliJ의 선택 확장](https://www.jetbrains.com/help/idea/working-with-source-code.html) 동작을 참고했으며, 이 앱의 지정 키는 ⌘D입니다. 프로그래밍 언어별 구문 분석 기반 선택은 제공하지 않습니다.

## 화살표 자동 변환

아래 입력을 **독립된 토큰으로 쓰고 Space**를 누르면 변환됩니다. 앞에는 줄 시작이나 공백이 필요합니다.

| 입력 | 변환 |
| --- | --- |
| `->`, `-->` | → |
| `<-`, `<--` | ← |
| `<->`, `<-->` | ↔ |
| `=>`, `==>` | ⇒ |
| `<=`, `<==` | ⇐ |
| `<=>`, `<==>` | ⇔ |

예: `원인 -> ` → `원인 → `. ⌘Z 한 번으로 변환 직전의 입력으로 돌아갑니다. 코드·링크·HTML 내부, 이스케이프한 입력, 붙여넣기, 한글 조합 중에는 변환하지 않습니다. 입력 중인 코드·링크 보호를 위해 백틱이나 `](`가 있는 줄에서도 변환하지 않습니다.

## 선택한 텍스트의 서식

먼저 한 문단 안의 텍스트를 선택한 다음 누르세요. 굵게·기울임·밑줄·취소선·인라인 코드로 감싼 텍스트 전체를 선택하고 같은 단축키를 다시 누르면 서식을 해제합니다.

| 서식 | 단축키 | 저장 형태 또는 동작 |
| --- | --- | --- |
| 굵게 | ⌘B | `**텍스트**` |
| 기울임 | ⌘I | `*텍스트*` |
| 밑줄 | ⌘U | `<u>텍스트</u>` |
| 취소선 | ⌘⇧S | `~~텍스트~~` |
| 인라인 코드 | ⌘E | 텍스트 양쪽을 백틱으로 감쌈 |
| 링크 추가 | ⌘K | URL 입력 창을 열고 선택한 텍스트에 링크 적용 |

**취소선은 ⌘⇧S입니다. ⌘X는 잘라내기입니다.**

링크는 `https://`, `http://`, `mailto:`로 시작하는 주소를 입력한 뒤 적용합니다. 본문 텍스트 선택이 없으면 ⌘K는 지식지도 검색창으로 이동하는 기존 명령이며, 검색창이 열려 있을 때 사용할 수 있습니다.

서식 단축키는 편집 가능한 본문에서 동작합니다. 코드 블록·표 원문에는 적용하지 않으며, 인라인 코드에는 ⌘E로 코드 서식을 해제할 수 있습니다. 여러 문단에 걸친 인라인 서식 적용과 선택 없이 이후 입력에 서식을 예약하는 기능은 지원하지 않습니다. 한글 등 입력기 조합 중에는 변환을 실행하지 않습니다.

## 문단·블록 전환

현재 줄 또는 선택한 줄들을 다음 형식으로 바꿉니다.

| 형식 | 단축키 |
| --- | --- |
| 일반 문단 | ⌘⌥0 |
| 제목 1 | ⌘⌥1 |
| 제목 2 | ⌘⌥2 |
| 제목 3 | ⌘⌥3 |
| 체크리스트 | ⌘⌥4 |
| 불릿 목록 | ⌘⌥5 |
| 번호 목록 | ⌘⌥6 |
| 코드 블록 | ⌘⌥8 |

제목 4~6은 아래의 Markdown 입력으로 만들 수 있습니다. ⌘⌥7의 토글 목록, ⌘⌥9의 페이지 생성은 현재 지원하지 않습니다.

## 불릿의 Tab과 Enter

| 현재 상태 | 키 | 결과 |
| --- | --- | --- |
| 불릿 항목 안 | Tab | 불릿과 본문을 함께 한 단계 들여쓰기 |
| 들여쓴 불릿 안 | ⇧Tab | 한 단계 내어쓰기 |
| 내용이 있는 불릿 | Enter | 같은 깊이에 새 불릿 생성 |
| 내용 없는 하위 불릿 | Enter | 불릿을 유지하고 한 단계 내어쓰기 |
| 내용 없는 최상위 불릿 | Enter | 불릿 해제, 일반 문단으로 전환 |
| 항목의 본문 맨 앞 | Backspace | 목록 형식 해제 |

예: 부모 불릿 → Enter → Tab → 자식 내용 입력 → Enter → **빈 하위 불릿** → Enter → **빈 최상위 불릿** → Enter → **일반 문단**.

깊이가 여러 단계면 빈 항목에서 Enter를 누를 때마다 한 단계씩 나옵니다. 최상위에 도달한 뒤 추가 Enter가 불릿을 해제합니다. 내용이 있으면 Enter는 다음 항목을 만드는 동작입니다.

Tab은 커서가 본문 중간에 있어도 항목 전체에 적용되며, 바로 이어진 하위 항목도 함께 이동합니다. Tab/⇧Tab은 번호 목록, `-`·`*`·`+` 불릿과 그 체크리스트에서 사용할 수 있습니다. 번호 목록에서 텍스트를 선택한 채 누르면 선택이 걸친 번호 항목을 함께 들여쓰거나 내어쓰고 선택을 유지합니다.

한 단계는 원문 공백 두 칸입니다. 첫 항목도 한 번 들여쓸 수 있지만, 앞선 부모 없이 계속 Tab을 눌러 코드 문법이 되는 깊이로 이동하지는 않습니다.

## 번호 목록·체크리스트·인용

| 종류 | 키 또는 조작 | 결과 |
| --- | --- | --- |
| 번호 목록 | 내용 뒤 Enter | 같은 깊이에 다음 번호 생성: 12 → 13 |
| 체크리스트 | 내용 뒤 Enter | 새 미완료 항목 생성 |
| 체크리스트 | 체크박스 클릭 | 완료·미완료 전환 |
| 빈 목록 항목 | Enter | 들여쓴 상태면 한 단계 내어쓰기, 최상위면 목록 종료 |
| 인용 | Enter | 인용을 끝내고 일반 문단으로 이동 |
| 인용 | ⇧Enter | 인용을 유지한 새 줄 생성 |
| 인용 본문 맨 앞 | Backspace | 인용 형식 해제 |

## 코드 블록·표

| 위치 | 키 | 결과 |
| --- | --- | --- |
| 코드 블록 | Tab | 공백 두 칸 삽입 |
| 코드 블록 | Enter | 코드 안에서 줄바꿈 |
| 코드 블록 | ⇧Enter | 코드 블록 뒤의 일반 문단으로 이동 |
| 코드 블록 끝 | 연속 빈 줄 뒤 Enter | 코드 블록에서 나가기 |
| 코드 블록 | ⌘A | 해당 블록의 코드 본문만 선택 |
| 빈 코드 블록 시작 | Backspace | 코드 블록 해제 |
| 표·다이어그램·코드 블록 바로 뒤 | Backspace | 해당 블록 전체 삭제. ⌘Z로 복원 |
| 블록 선택 중 | Backspace 또는 Delete | 선택한 블록 삭제. ⌘Z로 복원 |
| 블록 선택 중 | ⌘C / ⌘X | 선택한 블록의 Markdown 원문 복사 / 잘라내기 |
| 블록 선택 중 | Esc | 블록 선택 해제 |
| 블록 선택 중 | ⇧ + 여백에서 끌기 | 기존 선택에 지나간 블록 추가 |
| 블록 선택 중 | ⇧ + 블록 손잡이 클릭 | 기존 선택에 그 블록 추가 |
| 표의 셀 선택 | 방향키 | 해당 방향의 셀 선택 |
| 표의 셀 편집 | Enter | 셀 안에서 줄바꿈 |
| 표의 셀 편집 | Tab / ⇧Tab | 셀 편집 내용을 적용하고 다음 / 이전 셀로 이동 |

코드의 언어 변경과 본문 복사는 코드 패널의 언어 메뉴와 복사 버튼으로도 할 수 있습니다.

## Markdown 입력 규칙

줄 시작 입력은 **기호 뒤에 Space**를 눌러 완성합니다. 코드 안에서는 목록·인용 입력으로 바뀌지 않습니다.

| 원하는 형식 | 입력 |
| --- | --- |
| 불릿 | `-` 또는 `*` 또는 `+` 다음 Space |
| 번호 목록 | 숫자와 마침표 다음 Space: `1.` + Space |
| 미완료 체크리스트 | `- [ ]` 다음 Space 및 내용 |
| 완료 체크리스트 | `- [x]` 다음 Space 및 내용 |
| 제목 1~6 | `#` ~ `######` 다음 Space |
| 인용 | `>` 다음 Space |
| 인용 별칭 | 세로 막대 또는 큰따옴표 다음 Space |
| 코드 블록 | 백틱 세 개 + 언어 이름 + Enter, 예: 백틱 세 개 뒤 `python` 입력 |
| 굵게 | `**텍스트**` 또는 `__텍스트__` |
| 기울임 | `*텍스트*` 또는 `_텍스트_` |
| 취소선 | `~~텍스트~~` |
| 링크 | `[이름](https://example.com)` |

인용 별칭의 세로 막대는 `|`, 큰따옴표는 `"`입니다. 이 기호를 직접 입력하고 Space를 누르면 `> ` 원문으로 변환됩니다. 표 전체 붙여넣기는 인용으로 변환하지 않습니다.

밑줄은 ⌘U를 사용합니다. 일반 Markdown에 밑줄 전용 문법이 없어 HTML의 `<u>` 태그로 저장합니다.

## 적용 범위와 확인 근거

이 문서는 Stology Local에 구현된 동작을 설명합니다. [노션 공식 단축키](https://www.notion.com/help/keyboard-shortcuts)를 참고했지만 노션의 전체 명령을 제공하지는 않습니다. 특히 이 앱의 `>` + Space는 토글이 아닌 Markdown 인용입니다. `/` 메뉴, 색상·하이라이트 단축키, 댓글·토글·페이지 생성 단축키는 이 문서의 지원 범위에 포함되지 않습니다.

새 노트 제목 입력 중 Enter는 제목을 적용하고 본문으로 이동하며, Esc는 기본 제목을 유지합니다. 파일 검색·지도 검색 입력 중 Esc는 해당 검색어를 지웁니다.

## 학습도우미

채팅 입력창에서 Enter는 줄바꿈, ⌘Enter는 전송이다. 한글 조합 중에는 전송하지 않는다. 생성 중에는 다음 질문을 작성할 수 있고, 현재 응답이 끝난 뒤 전송할 수 있다. 메시지 본문은 선택·복사할 수 있으며 답변마다 복사 버튼이 있다. 중앙 문서의 서식 단축키를 채팅에 적용하지 않는다.

| 선택 삭제 · 해제 | Delete · Esc |
