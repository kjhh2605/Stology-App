# 노트 이미지

이미지를 복사한 뒤 노트 중간에서 `⌘V`로 붙여넣는다. 빈 초안에서도 사용할 수 있다.

- 네 모서리나 상하좌우 가장자리에 마우스를 올리면 방향에 맞는 크기 조절 커서가 표시됩니다. 이곳을 드래그하면 원래 비율을 유지하며 크기가 바뀐다.
- 모서리 인식 영역은 48×48pt, 상하좌우 가장자리는 32pt로 넓혔다. 작은 이미지에서는 가운데 이동 영역을 남기도록 조정한다.
- 이미지 몸체를 가로로 드래그하면 위치가 바뀌고, 남는 좌우 공간으로 본문이 흐른다.
- 우클릭 메뉴에서 이미지 삭제, 왼쪽/가운데/오른쪽 배치, 한 줄 전체 사용을 선택한다.
- `⌘A`는 이미지와 이미지의 마크다운 구문을 제외한 텍스트만 선택한다. 복사·삭제·새 텍스트 입력에서도 이미지를 보존한다.
- 이미지 테두리와 고정 크기 조절 표시는 표시하지 않는다.
- 삭제·크기·배치 변경은 네이티브 실행 취소/재실행 대상이다.

## 저장

파일은 `workspaces/<과목 ID>/files/이미지/<SHA-256>.png` 또는 `.jpg`에 저장한다. 같은 바이트는 재사용한다. 파일에서 복사한 PNG/JPEG는 원본 바이트를 보관하며, 클립보드 TIFF는 PNG로 변환한다. 파일당 20 MiB, 붙여넣기 시 4천만 픽셀 이내를 지원한다.

```markdown
![이미지](<../이미지/파일해시.png> "stology:width=280;x=0.500;wrap=1")

이미지 옆에서 이어지는 필기
```

이미지 문법은 표준 Markdown이다. 제목의 `stology:` 이후에 표시 너비(포인트), 가로 위치(남는 너비의 0~1 비율), 본문 둘러싸기 여부(1/0)를 기록한다. 다른 Markdown 뷰어에서도 상대경로 이미지는 열리지만 배치는 Stology 전용이다. 본문 필기는 별도 텍스트 상자나 HTML이 아니라 보통 Markdown 문단으로 저장한다. 세로 위치는 이미지가 들어 있는 문단 순서로 정해진다.

초안은 과목 `files`를 경로 기준으로 사용한다. 첫 저장과 폴더 이동 때 앱이 생성한 이미지 링크만 새 폴더 기준으로 보정한다. 코드 블록·일반 텍스트·외부 URL은 변경하지 않는다. 경로가 바뀌면 편집 내용도 새 경로로 갱신하고 이전 경로를 복구하는 실행 취소 기록은 초기화한다.

이미지 삭제는 노트 안의 참조를 제거한다. 첨부 파일은 실행 취소·다른 노트·원본 버전을 위해 남긴다. 자동 정리나 이미지 포함 내보내기 UI는 아직 없다. 노트를 외부로 옮길 때는 이미지 폴더와 상대경로 관계를 함께 보존해야 한다.

## 구현과 검증

- `core/src/storage.rs`: 내용 해시 저장, 초안 경로, 폴더 이동 기록과 중단 복구
- `shared/image_markdown.rs`: 이미지 레이아웃 문법과 관리 이미지 상대경로 보정
- `ui/src/image_edit.rs`: 클립보드, 메뉴 활성화, 이미지 컨트롤, 실행 취소
- `ui/src/editor.rs`: TextKit 2 exclusion paths로 실제 본문 줄을 이미지 주변에 배치
- `ui/examples/image-smoke.rs`: 붙여넣기 메뉴, 본문 보존, 줄 좌표, 삭제/실행 취소, 읽기 전용, 연속 이미지와 반복 레이아웃 검증

[TextKit exclusion paths](https://developer.apple.com/documentation/appkit/nstextcontainer/exclusionpaths)는 이미지 영역을 본문 줄 배치에서 제외한다.
