# 노트 이미지

이미지를 복사한 뒤 노트 중간에서 `⌘V`로 붙여넣는다. 빈 초안에서도 사용할 수 있다.

- 네 모서리나 상하좌우 가장자리에 마우스를 올리면 방향에 맞는 크기 조절 커서가 표시됩니다. 이곳을 드래그하면 원래 비율을 유지하며 크기가 바뀐다.
- 모서리 인식 영역은 48×48pt, 상하좌우 가장자리는 32pt로 넓혔다. 작은 이미지에서는 가운데 이동 영역을 남기도록 조정한다.
- 이미지와 다이어그램은 `한 줄 전체`, `왼쪽에 배치`, `오른쪽에 배치` 중 하나로 놓인다. 붙여넣으면 한 줄 전체로 시작한다. 가운데나 임의의 위치에는 놓을 수 없다.
- 왼쪽이나 오른쪽에 배치하면 바로 다음 블록 하나가 옆 칸에 놓인다. 옆 글은 자기 칸 안에서만 줄바꿈하고, 그다음 블록은 그림과 옆 블록 중 긴 쪽 아래에서 시작한다.
- 이미지나 다이어그램의 가운데를 잡고 끈다. 가운데가 본문 폭의 절반을 넘으면 오른쪽 칸으로, 오른쪽에 있던 그림을 되돌리면 왼쪽 칸으로 간다. 위아래로 끌면 선이 가리키는 블록 앞으로 옮겨진다. 끌고 있는 동안 예상 배치가 보이고, 놓으면 저장된다. 코드 블록과 표 안으로는 들어가지 않는다.
- 그림 옆 빈 자리를 클릭하면 옆 블록이 생겨 바로 쓸 수 있다. 다른 블록의 블록 손잡이를 그림의 왼쪽·오른쪽 가장자리로 끌어다 놓아도 옆 블록이 된다.
- 우클릭 메뉴에는 `한 줄 전체`·`왼쪽에 배치`·`오른쪽에 배치`와 삭제가 있고, 다이어그램에는 편집이 더 있다.
- 방향키로 이동할 때 커서는 그림의 숨겨진 링크 줄과 구분용 빈 줄을 건너뛴다.
- `⌘A`는 이미지와 이미지의 마크다운 구문을 제외한 텍스트만 선택한다. 복사·삭제·새 텍스트 입력에서도 이미지를 보존한다.
- 이미지나 다이어그램을 한 번 클릭하면 그림 바깥에 선택 테두리와 크기 조절 손잡이 여덟 개가 표시된다.
- 삭제·크기·배치 변경은 네이티브 실행 취소/재실행 대상이다.

## 저장

파일은 `workspaces/<과목 ID>/files/.images/<SHA-256>.png` 또는 `.jpg`에 저장한다. 같은 바이트는 재사용한다. `.images`를 포함한 점으로 시작하는 폴더와 macOS 숨김 속성 폴더는 자료 트리에서 하위 폴더·문서까지 숨긴다. 기존 `이미지/` 첨부 파일과 링크는 그대로 보존하며 새 붙여넣기부터 `.images/`를 사용한다. 파일에서 복사한 PNG/JPEG는 원본 바이트를 보관하며, 클립보드 TIFF는 PNG로 변환한다. 파일당 20 MiB, 붙여넣기 시 4천만 픽셀 이내를 지원한다.

```markdown
![이미지](<../.images/파일해시.png> "stology:width=280;x=0.000;wrap=1")

이미지 옆 칸에 놓이는 블록 하나
그림 아래에서 이어지는 필기
```

이미지 문법은 표준 Markdown이다. 제목의 `stology:` 이후에 표시 너비(포인트)와 배치를 기록한다. `wrap=0`은 한 줄 전체, `wrap=1;x=0.000`은 왼쪽 배치, `wrap=1;x=1.000`은 오른쪽 배치다. 이전 버전이 저장한 0~1 사이의 `x`는 0.5 미만이면 왼쪽, 이상이면 오른쪽으로 읽는다. 세로 거리 `y`는 더 쓰지 않으며, 그 그림을 다시 옮기거나 크기를 바꿀 때 기록에서 지운다. 열기만 해서는 파일을 바꾸지 않는다. 다른 Markdown 뷰어에서도 상대경로 이미지는 열리지만 배치는 Stology 전용이다. 옆 블록은 별도 텍스트 상자나 HTML이 아니라 그림 다음에 오는 보통 Markdown 줄이다. 그림 링크 다음의 빈 줄 하나는 구분용이라 화면에서 접는다. 문장 안에 들어 있는 이미지 링크는 블록이 아니므로 옮길 수 없고 크기만 조절한다.

표의 배치는 표 첫 칸의 `<!--stology-grid {...}-->` 주석에 열 너비·정렬과 함께 기록한다. `"wrap":true`는 왼쪽 배치, `"wrap":true,"side":"right"`는 오른쪽 배치이고 둘 다 없으면 한 줄 전체다.

초안은 과목 `files`를 경로 기준으로 사용한다. 첫 저장과 폴더 이동 때 앱이 생성한 이미지 링크만 새 폴더 기준으로 보정한다. 코드 블록·일반 텍스트·외부 URL은 변경하지 않는다. 경로가 바뀌면 편집 내용도 새 경로로 갱신하고 이전 경로를 복구하는 실행 취소 기록은 초기화한다.

이미지 삭제는 노트 안의 참조를 제거한다. 첨부 파일은 실행 취소·다른 노트·원본 버전을 위해 남긴다. 자동 정리나 이미지 포함 내보내기 UI는 아직 없다. 노트를 외부로 옮길 때는 이미지 폴더와 상대경로 관계를 함께 보존해야 한다.

## 구현과 검증

- `core/src/storage.rs`: 내용 해시 저장, 초안 경로, 폴더 이동 기록과 중단 복구
- `shared/image_markdown.rs`: 이미지 레이아웃 문법과 관리 이미지 상대경로 보정
- `ui/src/image_edit.rs`: 클립보드, 메뉴 활성화, 이미지 컨트롤, 배치와 이동, 실행 취소
- `ui/src/note_blocks.rs`: 블록 분해, 그림·표와 옆 블록의 행, 블록 이동(순수 문자열 처리와 단위 테스트)
- `ui/src/editor.rs`: 행 배치 계산(`arrange_rows`). 옆 글은 문단 들여쓰기로 자기 칸에 두고, 짧은 옆 블록 뒤에는 문단 간격을 더해 다음 블록을 행 아래에서 시작시킨다
- `ui/src/block_handles.rs`: 블록 손잡이, 블록 선택, 블록 이동
- `ui/examples/image-smoke.rs`: 붙여넣기 메뉴, 본문 보존, 칸 좌표, 좌·우·한 줄 전체 배치, 블록 사이 이동, 이전 세로 거리 무시, 삭제/실행 취소, 읽기 전용 검증
- `ui/examples/block-smoke.rs`: 행 배치, 옆 블록 클릭·놓기, 블록 손잡이 이동, 여백 선택과 삭제·복사·실행 취소 검증

본문 줄을 그림 주변으로 흘리던 TextKit exclusion paths는 더 쓰지 않는다. 옆 칸은 [문단 들여쓰기](https://developer.apple.com/documentation/appkit/nsparagraphstyle)로 만든다.

## 노트 다이어그램

편집 화면 상단의 ‘제목 없음’을 클릭해 이름을 입력합니다. 노트 제목처럼 Enter나 다른 곳 클릭으로 적용하고 Esc로 입력을 취소합니다. 완료를 누르면 이름과 그림이 함께 저장됩니다. 제목만 입력했거나 그린 내용을 모두 지운 상태에서 완료하면 기존 파일과 노트 본문을 유지한 채 돌아갑니다.

노트 상단의 다이어그램 버튼을 누르거나 ⌘⇧D를 입력하면 중앙에 캔버스가 열립니다. ⌘+·⌘−로 확대·축소하면서 도형을 그릴 수 있습니다. 대상을 선택한 뒤 오른쪽의 선 색·채우기·텍스트 색 중 바꿀 항목을 누르세요. 32개 기본색이나 최근 색을 누르면 바로 적용됩니다. 채우기에서는 첫 번째 칸을 누르면 채우기가 사라집니다. 도형은 채우기 없음으로 배경을 비울 수 있습니다. 도형을 더블클릭하면 글자를 넣을 수 있습니다. 화살표의 끝을 도형에 놓으면 도형을 움직일 때 함께 이동합니다.

화살표를 끄는 동안 끝이 붙을 도형에 보라색 테두리와 네 변 가운데의 점이 나타납니다. 점 가까이에 놓으면 끝이 그 변의 가운데에 고정됩니다. 같은 두 도형을 오가는 화살표가 겹칠 때 서로 다른 변에 고정하면 나눠 그릴 수 있습니다. Shift를 누른 채 끌면 수평·수직·45° 방향으로 맞춰집니다. 위쪽 도구 줄의 화살표 버튼을 누르면 **단방향 화살표**, **양방향 화살표**, **화살촉 없는 선** 가운데 하나를 고를 수 있고, 고른 종류로 바로 그립니다. 단축키 A를 누르면 마지막에 고른 종류로 그립니다. 그린 화살표를 우클릭하면 **점선으로 전환**, **꺾인 선으로 변환**, 화살표 종류 바꾸기 메뉴가 나옵니다. 꺾인 선은 도형 사이를 직각으로 잇고, 같은 메뉴의 **직선으로 변환**으로 되돌립니다. 화살표를 더블클릭해 글자를 넣으면 글자 자리만큼 선이 끊깁니다. 화살표를 여러 개 이어 그리려면 화살표 버튼 메뉴에서 **계속 그리기**를 고르세요. 다른 그리기 도구는 버튼을 더블클릭하면 됩니다. 버튼에 점이 표시되고, 다른 도구를 고르거나 Esc를 누를 때까지 도구가 유지됩니다.

**완료**를 누르면 선·화살촉·글자가 들어가는 최소 사각형으로 잘린 그림이 커서 자리에 들어갑니다. 그림을 한 번 클릭하면 선택 테두리와 여덟 개의 크기 조절 손잡이가 나타납니다. 노트에서 그림을 오른쪽으로 끌면 오른쪽 칸으로 옮겨지고, 바로 다음 블록 하나가 옆 칸에 놓입니다. 크기는 손잡이로 조절하고, 더블클릭이나 우클릭 메뉴의 **편집**으로 다시 엽니다.

그림과 편집 데이터는 과목의 `files/.diagram/<UUID>.svg`에 함께 저장됩니다. Markdown 링크는 노트 위치를 기준으로 하며 배치 값은 일반 이미지와 같습니다. 같은 파일을 가리키는 모든 노트에 수정한 그림이 반영됩니다. 링크를 지운 뒤에도 파일은 남습니다.
