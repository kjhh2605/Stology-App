# 공급자 식별 아이콘

구독 계정 연결 창과 HTML 3번 시안에서 공급자를 식별하는 용도로 사용한다. 각 상표의 권리는 해당 소유자에게 있다.

- `codex.svg`, `claude.svg`: [Lobe Icons](https://github.com/lobehub/lobe-icons)의 `packages/static-svg/icons/openai.svg`, `claude-color.svg`에서 2026-11-17 수집. Codex 항목은 사용자 요청에 따라 OpenAI Blossom 매듭 로고를 사용한다. [공식 브랜드 안내](https://openai.com/brand/)로 형태를 대조했으며, 벡터 파일의 배포 출처는 Lobe Icons이다. [MIT 라이선스](LICENSE-lobe-icons)를 포함한다.
- `codex.png`, `claude.png`: 위 SVG를 AppKit으로 128px에 렌더링한 앱 내장용 이미지.
- `antigravity.png`: [Google Antigravity 공식 press assets](https://antigravity.google/press)의 `antigravity-icon__full-color.png`. 2026-11-17 수집.

PNG는 Rust 실행 파일에 포함하여 설치 후 외부 파일이나 네트워크에 의존하지 않는다.
