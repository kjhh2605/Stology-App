<p align="center"><b>학습 개념을 중심으로 자료를 정리하는, 내 Mac 안의 개인 지식 작업실</b></p>

Stology App은 과목별로 자료를 모아 읽고, 쓰고, 필기하는 Mac 앱입니다. 자료를 골라 분석을 요청하면 그 안의 개념과 관계를 3D 지식지도로 그려 줍니다.

## 지원 파일 형식


| 자료                | 앱에서 할 수 있는 일                 |
| ----------------- | ---------------------------- |
| Markdown          | 편집, 분석                       |
| PDF               | 필기, 분석                       |
| PNG · JPEG · HEIC | 미리보기, 분석                     |
| PPTX              | 미리보기, 분석 (`.ppt`는 지원하지 않습니다) |


분석에는 이미 쓰고 있는 Codex 또는 Claude 구독을 연결합니다. 앱은 각 공급자의 공식 도구를 실행할 뿐이며 로그인 정보를 직접 저장하지 않습니다. 처음 보내기 전에 "선택한 자료의 추출 텍스트와 필요한 원본 이미지가 선택한 구독 공급자에게 전송된다"고 알립니다. 구독 연결이 실패해도 API 과금으로 바꾸지 않습니다.
